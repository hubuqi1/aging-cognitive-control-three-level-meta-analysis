# Extracted summary data and calculation workbooks

`after_calculated_data.xlsx`: Main extraction and effect-size calculation workbook.

`calculate_emotionlike_combine.xlsx`: Condition summaries for combining emotion-related conditions.

`caculate_congruency_effect.xlsx`: Condition summaries and congruency/interference-effect calculations.

`calculate_agegroup_combine.xlsx`: Information used to combine age subgroups.

These are study summary data extracted from reports, not participant- or trial-level raw data. Study/effect identifiers link the workbooks and analysis inputs. The three shared R scripts start from the prepared CSV files in `data/datasets/` or `data/ceiling/`; they do not recalculate all workbook entries automatically.
